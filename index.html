📎 Как это работает:
  1. Файл скачается на ваше устройство с правильным именем.
  2. Положите его в папку documents/{тема}/.
  3. Откройте documents/manifest.json и добавьте имя файла в массив темы.
  4. Если работаете с Git — закоммитьте файл и manifest.json.
💡 Ссылки можно добавлять и через documents/links.json — тогда их увидят все пользователи.
